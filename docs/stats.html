stat reference

46 StatDefinition impls, stat/stats/*.java, one file each, registered by hand in StatRegistry's static block. Dec = supportsDecimals(). Graph = supportsGraph(). Thr = supportsThreshold(). Cadence = the StatSource feeding it, per sampling pipeline. GPU/VRAM rows are opt-in, see hardware-sensors.html.
