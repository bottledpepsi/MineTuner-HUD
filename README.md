# MineTuner HUD

**Customisable performance and stats HUD for Fabric.**

MineTuner HUD replaces the vanilla debug screen with a HUD that shows only the stats you care about. Build as many lists
as you like, drag them anywhere, style them with themes, and benchmark your performance. It is client-side only, so it
works on any server.

## Install

Requires Minecraft 26.3+, Fabric Loader, Fabric API, Cloth Config API and Java 25+. Drop the jar in your `mods` folder,
launch the game, then press **H** (or run `/minetuner gui`) to open the editor.
